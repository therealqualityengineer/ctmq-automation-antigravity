# Test Plan: CTMQ-80 - [Client] Enforce mandatory fields and display red asterisk (*) on Add and Edit Client pages
**Jira Sub-task:** [QA Testing Antigravity](CTMQ-81)
**Status:** Automated (`9/9` Passing in `tests/clientMandatoryFields.spec.ts`)

### Summary & Objectives
Verify that the Add Client (`/client/new`) and View/Edit Client (`/client/:id`) pages display a red asterisk (`*`) indicator adjacent to all 6 mandatory field labels (`Full Name`, `Email`, `Address`, `City`, `State`, `ZIP`), omit the asterisk on non-marked fields (`County`, `Status`), and strictly enforce required-field validation across both the frontend UI (Add and Edit flows) and backend REST endpoints (`POST /api/clients` and `PUT /api/clients/{id}`) while preserving existing Client records and layout conventions.

### Preconditions & Setup
- Authenticated session as an active Staffing Admin / QA Engineer user.
- At least one existing active Client record available in the system for View/Edit mode verification and Zero Data Loss checks.
- Default `County` and active `Status` options seeded and available on Client forms.
